# Alan Lyu — Academic Homepage

This repository contains the source for [junfenglyu.github.io](https://junfenglyu.github.io), the academic homepage of Alan Lyu (吕骏峰), an undergraduate at Peking University interested in biophysics and computational neuroscience.

The site is built with [al-folio](https://github.com/alshedivat/al-folio) and deployed through GitHub Pages.

## Site structure

- `Alan Lyu`: biography, research interests, contact details, and profile links
- `Research & Publications`: reserved for research summaries and publications
- `Lecture Notes`: reserved for course notes and learning materials
- `CV`: current PDF CV and a future web version

## Content locations

- Page content: `_pages/`
- Publication bibliography: `_bibliography/papers.bib`
- Profile and content images: `assets/img/`
- CV and other documents: `assets/pdf/`
- Social links: `_data/socials.yml`
- Site settings: `_config.yml`

## Development

The upstream template is tracked as `upstream`, while `origin` points to the personal GitHub Pages repository. See `docs/INSTALL.md` and `docs/CUSTOMIZE.md` for the al-folio development workflow.
